# Hvor er den? 2.2 – Lister og tur

Arbeidsgren: `agent/v22-lists-trips`

- Gratisplan: opptil 5 medlemmer per hjem, inkludert eieren.
- Ny hovedfane: Lister. Rom er fortsatt tilgjengelig fra Hjem og Profil.
- Pakkeliste, huskeliste, handleliste, flytteliste, tur og egen liste.
- Turdata: sted, fra-/til-dato og fremdrift.
- Ferdige maler: helgetur, sydenferie, hyttetur, jobbreise, tur med Tica og flytting.
- Listepunkter kan kobles til registrerte ting og viser hvor de ligger.
- Finn og pakk-modus samt pakk-ut-modus som viser hvor ting skal tilbake.
- Delte og private lister.
- Premium er bare forberedt visuelt; ingen betaling er aktivert.

Produksjonsappen på `main` endres ikke før grenen er validert og klar.
